# Gamity-TFG

Descripción:
Gamity es una plataforma web diseñada para conectar jugadores de cualquier tipo tanto competitivo como casual. El objetivo es facilitar la interacion de personas con los mismos gustos y divertirse jugando casualmente o apoyarse para lograr sus metas competitivamente

-- Tecnologías utilizadas
-Backend: PHP 8.x (Arquitectura MVC)
-Base de Datos: MySQL (phpMyAdmin)
-Frontend: HTML5, CSS3, JavaScript
-Diseño: Bootstrap 5 (Responsive)
-Infraestructura: Docker & Docker Compose
--Control de Versiones: Git & GitHub
